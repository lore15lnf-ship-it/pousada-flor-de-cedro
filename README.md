# Pousada Flor de Cedro — Sistema de Reservas

**Disciplina:** Análise e Projeto de Sistemas
**Professor:** Euller da Silva Ferreira
**Aluna:** Lorena Do Nascimento Ferreira
**Curso:** Sistemas de Informação

## Descrição
Sistema web de gestão de reservas para a Pousada Flor de Cedro, que conta com 8 cabanas exclusivas (categorias Clássica, Superior e Premium). O sistema resolve o problema de overbooking, perda de informações e lentidão no atendimento, centralizando o processo de reserva.

## Funcionalidades implementadas
- Catálogo de cabanas
- Consulta de disponibilidade por datas
- Reserva online com fluxo em 3 etapas (datas, dados do hóspede e pagamento)
- Painel administrativo para a recepcionista (login e cancelamento de reservas)
- Banner de consentimento LGPD
